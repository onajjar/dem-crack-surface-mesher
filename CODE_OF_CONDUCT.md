# Code of Conduct

## Our standards

Contributors and maintainers are expected to communicate respectfully, welcome constructive technical disagreement, and focus feedback on the work rather than the person. Harassment, discrimination, intimidation, personal attacks, and publication of another person's private information are not acceptable.

Scientific claims, benchmarks, and generated artifacts must be presented honestly, with limitations and reproducibility information made clear. Safety, licensing, provenance, and confidentiality concerns should be raised promptly and handled in good faith.

## Scope

This code of conduct applies in repository issues, pull requests, discussions, reviews, and other project spaces. It also applies when someone is representing the project in public.

## Reporting and enforcement

Report unacceptable behavior privately through the maintainer's GitHub profile. Security vulnerabilities should follow [SECURITY.md](SECURITY.md) instead. Reports will be reviewed as confidentially as practical, and maintainers may edit or remove contributions, issue warnings, temporarily restrict participation, or permanently ban participants when necessary.
